# 冰原營地 · Polar Camp

原創 Three.js 3D 雪地經營網頁遊戲，玩法依使用者提供的試玩影片重做。正式站：https://beargame-theta.vercel.app

**獵熊 → 搬肉 → 販售 → 收錢 → 升級 → 擴張**，共五關，每關從手動經營一路升級到全自動營地。

## 功能總覽

### 核心循環
- 營地外有三群密集獵物（北、西、南），東側是客人排隊的雪道。靠近獵物自動揮砍，一次砍到扇形內的所有目標，移動中也能攻擊。
- 獵物倒下掉肉，走過去自動撿起，疊成背上的肉柱；背包上限可升級。
- 回營走到販售桌旁，整疊肉自動上桌；客人到桌前取走一份付錢，錢留在桌邊的收款處，玩家走過去才收進錢包（或由收銀員代收）。
- 站到地面標記上，錢會一張張飛進標記、價格倒數到 0 就升級；中途離開會保留已付金額。
- 柵欄是實體邊界，只能從北門或南門進出；點地面前往時會自動繞門、繞過營地四角。
- 營地內自動回血；倒下會回營，背上的肉保留。
- 卡通化受擊表現：獵物被砍會壓扁彈飛閃紅、頭甩後，咬人會跳起撲擊，死亡會飛上天翻圈、四腳朝天亂踢再洩氣消失，重生從雪裡彈出；掉肉從身上噴出落地（無對話框）。

### 地面標記（升級）
| 標記 | 效果 | 價格（第 1 關） |
| --- | --- | --- |
| 武器 | 六把外觀不同的武器：獵刀 → 鐵劍 → 寬刃劍 → 大劍 → 霜刃 → 極光劍，傷害、範圍、扇角、速度提升，揮砍顏色跟著變 | 45 / 100 / 200 / 400 / 800 |
| 上限 | 背包 +20 份 | 10 / 60 / 150 / 300 / 600 |
| 速度 | 移動 +15% | 100 / 250 / 500 / 900 |
| 獵場 | 獵物 +6 隻（上限 60） | 320 / 700 / 1500 |
| 助手 | 自動撿肉送到桌上（售出 30 份後解鎖） | 425 |
| 箭塔 | 西北角門外箭塔自動射擊，射程與傷害三級 | 150 / 400 / 900 |
| 收銀員 | 桌邊現金自動進錢包（售出 60 份後解鎖） | 350 |

助手、箭塔、收銀員、獵人四項齊全後 HUD 顯示「全自動運轉」。後面關卡的價格依關卡倍率上調。

### 建築與營地擴建
- 第一次買武器、上限、速度、助手、收銀員、獵人時，營地裡會蓋出對應建築：鍛造台、肉倉、雪橇棚、搬運小屋、收銀亭、獵人小屋，落成有長出動畫。
- 肉倉蓋好後販售桌容量從 240 升到 400。
- 營地隨建築數量真的變大：第 1 棟開西側土地、第 3 棟開南側、第 5 棟再開遠西側，柵欄與門跟著重建，碰撞與路徑同步更新。

| 2 | 冰湖營地 | 北極熊 28、雪狼 10 | 6 | ×1.25 | 40 | 3,000 |
| 3 | 冰川哨站 | 北極熊 30、雪狼 12、巨熊 2 | 8 | ×1.6 | 50 | 7,000 |
| 4 | 極光營地 | 北極熊 32、雪狼 16、巨熊 4 | 10 | ×2 | 60 | 15,000 |

- 獵物：北極熊（生命 30、掉 3 份）、雪狼（生命 18、掉 2 份、速度快）、巨熊（生命 260、掉 18 份、橘色生命條）。
- 每關三顆星：達成收入目標 → 收入達目標兩倍 → 營地全自動運轉（第 5 關為收入 20,000 / 40,000 / 全自動）。星等顯示在關卡進度條、故事卡與暫停選單，各關最佳星等會保存。
- 達成收入目標後左上出現「下一關」按鈕，也可以留下繼續賺錢；每關是一座新營地，從 0 元、0 升級重新開始。暫停選單可重玩已解鎖的關卡。每關有自己的色調與場景：第 2 關起有冰湖與冰晶、第 3 關起北方冰川崖壁、第 4 關起飄動的極光、第 5 關營地火炬夜景。

### 故事
- 五關串成一段原創故事：村長託付柴火錢、老獵人的冰窖、哨站的雪橇隊、極光下的長屋、最後的永凍要塞。
- 每關開始出現故事卡（講述者、引言、目標理由），達標出現結尾卡並帶出下一關的鉤子；關卡進度列顯示目標理由。

### 名字與戰績
- 開場／暫停選單可輸入獵人名字（12 字內），HUD 顯示名字與本關擊倒數。
- 暫停選單顯示本關擊倒、生涯擊倒、生涯收入與各關最佳成績；資料隨存檔保存並跨關累計。
- 沒有全球排行榜：純前端無法防作弊且需要後端，待確認需求後再加。

### 介面與操作
- 電腦：WASD／方向鍵移動，點擊地面前往；左上提示可點擊自動前往下一步。
- 新手引導：第一次掉肉、第一次背肉、第一次桌邊有錢、第一次錢夠升級時，地面對應位置會出現脈動的金色光環並提示一次；提示隨存檔記住，不會重複。
- 手機／平板：手指按在畫面任何位置會出現浮動搖桿，拖曳移動；快速點一下走到該點。
- 右上錢包、重玩、暫停；左上標題、下一步提示、關卡進度；下方背包數與自動化進度。地面標記只顯示圖示、價格與名稱，走近時說明顯示在上方提示列。
- 右下角常駐顯示版本（例如 `v1.16.0 · 7a78fa6 · 10/15 13:05`：套件版本 · Git 提交 · 建置時間），暫停選單也有；長時間開著的分頁偵測到新版本時會出現更新按鈕。
- 自製 SVG 圖示（HUD 與地面標記共用），不使用 emoji。安全區 CSS、固定頁面不捲動、背景自動暫停、本機自動存檔。
- 暫停面板可切換音效、畫質與重置進度。

## 啟動

需 Node.js 22.12+。

```sh
npm ci
npm run dev
```

```sh
npm test        # 模擬邏輯測試
npm run check   # 語法檢查
npm run build   # 產生 dist/
npm run preview
```

`dist/` 可部署到任何靜態網站服務；專案已設定 Vercel（`vercel.json`），推送 main 即自動部署。GitHub Actions（`.github/workflows/ci.yml`）會在 push 與 PR 時跑測試、語法檢查與建置。請透過 Vite 或靜態伺服器開啟，不要用 `file://`。網址加 `?debug` 會在 `window.__polar` 提供測試掛鉤（讀取狀態、瞬移）。

## 架構

- `src/sim.js`：純邏輯模擬（不依賴 Three.js／DOM）：移動與柵欄、戰鬥、掉落、販售、收款、標記付款、關卡、存檔驗證與舊版遷移（版本 7，相容 2–6）。
- `src/stages.js`：關卡表、獵物數值與主題色。
- `src/progression.js`：地面標記與價格、武器與箭塔數值、助手與獵人行為、自動化判定、關卡星等。
- `src/camp.js`：營地幾何、兩個門、柵欄碰撞、繞門與繞角路徑。
- `src/customers.js`：客人排隊與取肉。
- `src/guide.js`：下一步提示與標記文字。
- `src/art.js`：原創程序化角色、三種獵物、六把武器、箭塔、枯樹。
- `src/icons.js`：原創 SVG 圖示。
- `src/storage.js`：localStorage 存檔與備份。
- `game.js`：Three.js 場景、特效、輸入、HUD、選單與固定 30 Hz 模擬迴圈。
- `tests/`：模擬測試。`docs/GDD.md` 為規格與每次發布的設計記錄，`docs/VIDEO-STUDY.md` 為影片研究。

## 驗證與限制

- 模擬：53 項 Node.js 測試、語法檢查、Vite 建置。
- 瀏覽器：Playwright + Chromium（軟體算圖）在 iPhone／iPad 直橫向與桌機視窗截圖驗證主要畫面與觸控操作，無主控台錯誤。
- 真機：尚未在 iPhone／iPad／桌機瀏覽器實測觸控手感與 FPS；第 4、5 關同屏最多 60 隻獵物，需實測後決定是否調整。

存檔只存在本機瀏覽器，不跨裝置同步。所有模型與圖示由程式建立，不使用其他遊戲的商標或素材。
