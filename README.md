# 冰原營地 · Polar Camp

原創 Three.js 3D 雪地經營網頁遊戲。

**打熊 → 搬肉 → 加工 → 烹調 → 販售 → 擴建**

## 啟動

需 Node.js 22.12+（開發時使用 Node.js 24）。

```sh
npm ci
npm run dev
```

開啟終端機顯示的網址。手機與電腦在相同區域網路時，可使用電腦的區域網路 IP 測試。

```sh
npm test
npm run check
npm run build
npm run preview
```

`dist/` 為可部署至任意靜態網站服務的成品。不要直接以 `file://` 開啟原始 HTML；請透過 Vite 或靜態伺服器。

## 操作

- 電腦：WASD／方向鍵移動，也可以點擊地面前往目標。
- 手機／平板：拖曳左下虛擬搖桿；支援直向與橫向版面。
- 靠近熊：移動中也會自動攻擊，靠近掉落物自動拾取。
- 站進切肉台前方圓圈：卸下生肉，等待加工後自動取得肉排。
- 站進烤爐前方圓圈：卸下肉排，烤好後自動取得餐點。
- 站進販售櫃台前方圓圈：卸下餐點，排隊客人自動購買。
- 擴建營地：金幣升級武器、容量、生產速度，解鎖北方獵場與第二烤爐，聘請助手接手肉排及餐點運輸。
- 營地內自動回血；倒下會回營，保留物資。沒有夜襲、飢餓與燃料系統。
- 暫停面板可以切換音效、畫質，以及確認後重置進度。

## 本版內容

- Three.js 正交斜俯視場景；原創程式化角色、北極熊、設備、雪松、圍欄。
- 生肉／肉排／餐點分開計算，角色背包顯示堆疊。
- 獵物追擊、重生、拾取、排隊販售、三項五級升級。
- 180 金幣擴建；240 金幣聘請助手。
- `localStorage` 自動儲存、背景暫停、觸控取消、WebGL 中斷提示。
- 安全區與動態視窗高度 CSS、低畫質選項、首次互動啟用音訊。
- 無外部素材請求、無帳號、無廣告或付款。

## 架構

- `src/sim.js`：可獨立執行的遊戲邏輯、經濟、工作站、存檔。
- `game.js`：Three.js 視覺、音效、輸入、UI 與固定 30 Hz 模擬迴圈。
- `style.css`：桌機／手機／平板版面。
- `tests/sim.test.js`：完整經營循環、資源保全、助手、升級與存檔測試。
- `docs/GDD.md`：依使用者確認方向精簡後的本版規格。

## 驗證與限制

已通過 9 項 Node.js 邏輯測試、JavaScript 語法檢查及 Vite 生產建置。

本次執行環境未提供瀏覽器 QA，因此尚未驗證實際畫面、真實觸控、Safari 相容性或任何裝置的 FPS；不可將這些測試結果視為已通過 iPhone／iPad 實機驗收。此版是可執行的初版，尚非三區、長線養成及商業化版本。

存檔僅存在本機瀏覽器，不跨裝置同步；停留背景時不會計算離線收入。模型皆由程式建立，沒有使用 Whiteout Survival 的商標或遊戲素材。
