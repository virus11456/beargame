# 冰原營地 · Polar Camp

原創 Three.js 3D 雪地經營網頁遊戲，玩法依使用者提供的試玩影片重做。

**獵熊 → 搬肉 → 販售 → 收錢 → 升級 → 擴張**，共五關：雪原營地、冰湖營地（雪狼）、冰川哨站（巨熊）、極光營地、永凍要塞（終局）。每關是一座新營地，達成收入目標即可前往下一關；已解鎖的關卡可在暫停選單重玩。

## 啟動

需 Node.js 22.12+。

```sh
npm ci
npm run dev
```

```sh
npm test        # 模擬邏輯測試
npm run check   # 語法檢查
npm run build   # 產生 dist/
npm run preview
```

`dist/` 可部署到任何靜態網站服務；專案已設定 Vercel（`vercel.json`）。請透過 Vite 或靜態伺服器開啟，不要用 `file://`。

## 操作

- 電腦：WASD／方向鍵移動，點擊地面前往；左上提示可點擊自動前往下一步。
- 手機／平板：拖曳左下搖桿。
- 靠近熊自動揮砍，一次砍到扇形內的所有熊；走過肉塊自動撿起，疊在背上。
- 走到販售桌旁整疊肉自動上桌；客人排隊取肉付錢，錢留在桌邊的收款處，走過去才會收進錢包。
- 站到地面標記上，錢會一張張飛進去，價格倒數到 0 就升級：武器、上限、速度、獵場、助手。
- 營地內自動回血；倒下會回營，背上的肉保留。暫停面板可切換音效、畫質與重置進度。

## 架構

- `src/sim.js`：純邏輯模擬（不依賴 Three.js／DOM）、經濟、存檔驗證與舊版遷移。
- `src/stages.js`：關卡表、獵物數值與主題色。
- `src/progression.js`：地面標記、價格、武器數值、助手行為。
- `src/camp.js`：營地幾何、柵欄碰撞與門口路徑。
- `src/icons.js`：原創 SVG 圖示。
- `src/customers.js`：客人排隊與取肉。
- `src/guide.js`：下一步提示與標記文字。
- `src/art.js`：原創程序化角色、北極熊、枯樹。
- `game.js`：Three.js 場景、特效、輸入、HUD 與固定 30 Hz 模擬迴圈。
- `tests/`：模擬測試。`docs/GDD.md` 為規格，`docs/VIDEO-STUDY.md` 為影片研究。

## 驗證與限制

39 項模擬測試、語法檢查、Vite 建置通過；以 Playwright + Chromium 軟體算圖在手機與桌機視窗截圖確認主要畫面無錯誤。尚未在 iPhone／iPad／桌機瀏覽器實測觸控手感與 FPS。

存檔只存在本機瀏覽器，不跨裝置同步。所有模型由程式建立，不使用其他遊戲的商標或素材。
