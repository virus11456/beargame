# 試玩影片研究與本機改版

參考：使用者上傳的「寒霜啟示錄廣告試玩 #gameplay_720p.mp4」，長 193.28 秒。檢視方法：全時間軸每 4 秒抽樣，交易段 6–16 秒每秒 2 張加密檢視，並檢視 190 秒畫面。這是畫面研究，未聲稱已驗證音效或逐幀完整播放。

## 可直接從畫面確認

- 約 6–9 秒：角色背著長肉堆回到桌邊，肉轉移到桌上，客人在另一側排隊。
- 約 9–13 秒：客人持續取貨離隊，桌旁出現綠色現金堆；錢包仍顯示 0。
- 約 14–16 秒：角色靠近現金堆，鈔票移向角色，錢包由 0 增加。
- 中段：大量掉肉與高背包堆疊，狩獵和回營往返是主要操作。
- 後段：商品及現金都能堆高，角色走到地面標記花錢升級。
- 這份影片中的交易桌沒有清楚顯示獨立加工和烹調步驟；本遊戲仍依使用者先前指定，保留加工 → 烹調。

## 本輪實作

1. 顧客實際到櫃台才取走一份熟肉，離開時持有熟肉。
2. 付款進入 pendingCash，留在收款區；玩家靠近才轉入可花費的 coins。earned 表示已完成交易的累計收入，不因收取重複增加。
3. 現金堆依未收現金顯示，最多畫 90 塊並以數字顯示完整金額；熟肉展示最多 60 塊，庫存不因顯示上限截斷。
4. 顧客頭上顯示「烤肉 ×1」或「已取餐」，引導可帶玩家前往收款區。
5. 存檔版本 5 保留未收款；版本 2–4 遷移不追補過去收入，避免重複給錢。
