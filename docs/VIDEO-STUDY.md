# 試玩影片研究（2026-10-15 重新逐段檢視）

來源：使用者上傳的試玩錄影 `gameplay.mp4`（193 秒，640×360，直式畫面置中、兩側模糊填充）。方法：裁切中央直式區域，每 2 秒取一張、以 12 張一組的拼圖人工檢視全長；關鍵段落另外逐秒檢視。這是畫面研究，不含音效。

## 影片中可直接確認的機制

- **熊群**：營地外同時有二、三十隻北極熊擠在一起，每隻頭上有小型紅黑生命條。熊不會主動衝進營地。
- **揮砍**：角色拿一把劍，攻擊時出現大片粉紅色扇形揮砍特效與黃色命中閃光，一次打到周圍多隻熊，倒下的熊噴出大量粉紅色肉塊散落一地。
- **搬運**：角色走過肉塊就自動撿起，肉在背上疊成很高的直柱（常常高出畫面）。
- **販售桌**：回營後肉塊飛到桌上疊成紅色直柱；客人穿棕色大衣在圍欄外的雪道排隊，前排客人頭上有肉的對話泡泡，拿走一份肉後離開。
- **現金**：客人付的錢以綠色鈔票堆在桌邊，錢包數字不變；角色走過去時鈔票飛向角色、錢包才增加，背上也會出現綠色鈔票柱。
- **地面標記升級**：營地地面有數個方形標記，上面是圖示與價格（例：劍 45／100／200、堆疊 10、熊 425／370／320、「上限」）。角色站上去時鈔票一張張飛進標記、價格倒數（200 → 195），中途離開價格會停在已付的數字；付清後角色腳下出現綠色光圈，武器範圍變大。
- **介面**：左上遊戲標題與按鈕、右上綠色鈔票錢包；左下搖桿與「拖曳以移動」提示。
- **影片中沒有**切肉台、烤爐或任何半成品步驟；肉直接從桌上賣給客人。

## 本版對應實作

| 影片 | 本版 |
| --- | --- |
| 大群北極熊、各有生命條 | 起始 24 隻（最多 48）、生命 30、7 秒重生、生命條 |
| 寬扇形揮砍打多隻 | 扇形範圍內全部命中，粉紅扇形＋黃核心＋火花血滴 |
| 肉塊散落、自動撿起、背上高柱 | 每隻熊 3 份、2 單位內自動撿、實體化網格肉柱 |
| 肉直接堆上桌、客人排隊取肉 | 桌上庫存、客人到位才取一份付 5 元 |
| 現金留在桌邊、走過去才收 | 收款處鈔票堆，靠近才逐張收進錢包 |
| 踩標記逐步扣款、價格倒數、保留已付 | 每 0.05 秒扣一筆、已付金額存檔、升級後需離開再踩 |
| 標題／錢包／搖桿提示 | 同樣版面；標題與美術為原創，不使用影片品牌素材 |

## 仍有差異或未驗證

- 影片升級價格與熊數量只能部分辨識，本版價格為自訂平衡。
- 影片熊群密度更高、角色更小；本版為了手機效能先以 48 隻為上限。
- 真機觸控手感、FPS 與 Safari 相容性尚未實測。
