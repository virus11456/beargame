# 冰原營地：玩法規格（2026-10-15 依試玩影片重訂）

使用者於 2026-10-15 指出前一位開發者做出的玩法與上傳的試玩影片不同，並指定「以影片玩法為準」。本文件取代先前的切肉 → 烤爐 → 櫃台產線規格；影片逐段分析見 VIDEO-STUDY.md。

## 核心循環（與影片一致）

**獵熊 → 搬肉 → 販售 → 收錢 → 升級 → 擴張**

1. 營地外是一大群北極熊（起始 24 隻，每隻生命 30，死亡 7 秒後在原地附近重生）。熊平時在出生點附近遊走，玩家靠近 6 單位內才會追上來咬人。
2. 玩家只有一把劍。靠近熊就自動揮砍，一次揮砍打到扇形範圍內的所有熊（起始範圍 2.7、扇角約 120°、傷害 12、間隔 0.5 秒），移動中也能揮砍。
3. 每隻熊掉 3 份生肉。走過去自動撿起，肉在背上疊成直柱；起始上限 30 份，每級「上限」+20。
4. 回營地走到販售桌旁，整疊肉自動快速搬到桌上（每 0.035 秒一份）。桌上肉堆最多 240 份。
5. 客人在圍欄外的雪道排隊，走到桌前才取走一份生肉並付 5 元，拿著肉離開，再排到隊尾。沒有肉或客人沒到位就不會入帳。
6. 現金留在桌旁的收款處，玩家走過去才會逐張飛進錢包；未收的錢不能用來升級。
7. 營地地面有升級標記。玩家站上去時，錢會一張一張飛進標記，價格倒數到 0 才升級；中途離開會保留已付金額。升級完成後需離開標記再踩一次才會開始下一級，避免連續扣款。
8. 熊咬人每次 2 點生命、最多同時 3 隻咬；營地內每秒回 10、營地外每秒回 1.2。倒下會回到營地，背上的肉保留。

## 畫面與操作

- 斜 45° 正交鏡頭跟隨玩家；營地是木樁圍欄圍起的泥土地，北側開口兩旁放紅色格柵門板，客人雪道在東側。
- 揮砍顯示粉紅扇形與黃色核心；命中有黃色火花與血滴；熊有生命條，受傷時微縮。
- 背上肉柱與鈔票柱、桌上肉柱、收款處鈔票堆都用實體化網格顯示實際數量。
- 畫面右上為錢包、暫停、重玩；左上為標題與下一步提示（可點擊自動前往）；下方顯示背包數。
- PC：WASD／方向鍵、點地面前往；手機：左下搖桿「拖曳以移動」。安全區 CSS、背景自動暫停、本機存檔保留。

## 自動化階段、箭塔、三面熊群與戰績（2026-10-15 第六次發布）

### 武器外觀

### 熊群分布與門
獵物分成三個密集群：北、西、南，各群由內向外分層（巨熊在群的外圈），東側留給客人雪道。營地南側新增第二個門；路徑規劃會選較近的門，門外路線會繞過營地四角，不再穿越柵欄（玩家點地、助手、獵人共用）。

## 獵物受擊動畫（2026-10-15 第八次發布）

使用者要求北極熊被攻擊要有動畫，並且要誇張、搞笑。全部在畫面層完成，模擬只多帶命中來源與掉肉起點。

- 受擊：整隻往反方向彈飛並壓扁再回彈，頭甩到後面、瞬間放大，閃紅光；每隻獵物有自己的材質副本，不會整群一起閃。
- 咬人：跳起來往前撲，頭放大。
- 死亡（1.4 秒）：先飛上天翻兩圈，落地四腳朝天亂踢、頭搖晃，最後像氣球洩氣壓扁消失並冒白煙；屍體不再瞬間消失。
- 重生：從雪裡彈出來並過衝回彈。
- 掉肉：從獵物身上噴出來、拋物線落到地面。
- 原本加的吐槽泡泡依使用者指示（不要對話框）已移除，只保留動作表現。
- 箭塔與獵人的命中同樣觸發反應。

## 助手卡住修正（2026-10-15 第九次發布）
