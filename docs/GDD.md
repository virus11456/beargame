# 冰原營地：玩法規格（2026-10-15 依試玩影片重訂）

使用者於 2026-10-15 指出前一位開發者做出的玩法與上傳的試玩影片不同，並指定「以影片玩法為準」。本文件取代先前的切肉 → 烤爐 → 櫃台產線規格；影片逐段分析見 VIDEO-STUDY.md。

## 核心循環（與影片一致）

**獵熊 → 搬肉 → 販售 → 收錢 → 升級 → 擴張**

1. 營地外是一大群北極熊（起始 24 隻，每隻生命 30，死亡 7 秒後在原地附近重生）。熊平時在出生點附近遊走，玩家靠近 6 單位內才會追上來咬人。
2. 玩家只有一把劍。靠近熊就自動揮砍，一次揮砍打到扇形範圍內的所有熊（起始範圍 2.7、扇角約 120°、傷害 12、間隔 0.5 秒），移動中也能揮砍。
3. 每隻熊掉 3 份生肉。走過去自動撿起，肉在背上疊成直柱；起始上限 30 份，每級「上限」+20。
4. 回營地走到販售桌旁，整疊肉自動快速搬到桌上（每 0.035 秒一份）。桌上肉堆最多 240 份。
5. 客人在圍欄外的雪道排隊，走到桌前才取走一份生肉並付 5 元，拿著肉離開，再排到隊尾。沒有肉或客人沒到位就不會入帳。
6. 現金留在桌旁的收款處，玩家走過去才會逐張飛進錢包；未收的錢不能用來升級。
7. 營地地面有升級標記。玩家站上去時，錢會一張一張飛進標記，價格倒數到 0 才升級；中途離開會保留已付金額。升級完成後需離開標記再踩一次才會開始下一級，避免連續扣款。
8. 熊咬人每次 2 點生命、最多同時 3 隻咬；營地內每秒回 10、營地外每秒回 1.2。倒下會回到營地，背上的肉保留。

## 畫面與操作

- 斜 45° 正交鏡頭跟隨玩家；營地是木樁圍欄圍起的泥土地，北側開口兩旁放紅色格柵門板，客人雪道在東側。
- 揮砍顯示粉紅扇形與黃色核心；命中有黃色火花與血滴；熊有生命條，受傷時微縮。
- 背上肉柱與鈔票柱、桌上肉柱、收款處鈔票堆都用實體化網格顯示實際數量。
- 畫面右上為錢包、暫停、重玩；左上為標題與下一步提示（可點擊自動前往）；下方顯示背包數。
- PC：WASD／方向鍵、點地面前往；手機：左下搖桿「拖曳以移動」。安全區 CSS、背景自動暫停、本機存檔保留。

## 存檔

版本 6。保存玩家位置與面向、錢包、未收現金、肉、桌上庫存、升級、各標記已付金額、熊群、掉落物、客人與助手。版本 2–5 的舊存檔會保留錢包（含未收款）、累計收入、擊殺、售出、武器／上限／速度等級與助手旗標，其餘重新開始。

## 本版排除

沒有切肉台、烤爐與中間半成品；沒有夜襲、飢餓、溫度、燃料、付費、廣告、每日任務。圍欄只是視覺邊界。

## 驗證狀態

- 模擬：32 項 Node.js 測試（扇形多目標、掉落撿取、桌上販售、收款、標記逐步付款與保留、助手、存檔遷移）、語法檢查、Vite 建置通過。
- 瀏覽器：以 Playwright + Chromium（軟體算圖）在 390×844 與 1280×800 截圖驗證戰鬥、卸貨、客人付款、收款、付款升級畫面，無主控台錯誤。軟體算圖幀率很低，不代表真機效能。
- 真機：尚未在 iPhone／iPad／桌機瀏覽器實測觸控手感與 FPS。

## 手機與 iPad 版面（2026-10-15 第二次發布）

- 觸控裝置的像素比上限 1.5、陰影貼圖 1024，直向鏡頭稍微拉近。
- 以 Playwright 在 390×844、844×390、820×1180、1180×820 四種視窗截圖，並以合成觸控事件驗證搖桿出現、移動與點擊前往。真機手感仍待實測。

## 柵欄碰撞（2026-10-15 第三次發布）

- 柵欄是實體邊界：玩家只能從北側門口（x 1.3–5.9）進出，其他方向會被擋住。點地面或提示前往時會先繞到門口再走向目標。
- 熊的出生點全部在柵欄外，且每一步都會被推回柵欄外；助手往返獵場與販售桌也走門口。
- 新增 `src/camp.js` 共用營地幾何；測試 34 項。

## 自製 SVG 圖示（2026-10-15 第四次發布）

- 以 `src/icons.js` 提供一組原創 24×24 平面圖示：武器、上限、速度、獵場、助手、鈔票、肉、暫停、重玩、鎖定、完成、箭頭、導航。HUD 以內嵌 SVG sprite 使用，不再依賴 emoji。

### 進度與節奏

- 每關從 0 元、0 升級開始；上一關的累計收入記入 `lifetime` 作為紀錄。達成收入目標後出現「下一關」按鈕，也可以留在本關繼續賺錢。
- 已解鎖的關卡可在暫停選單重玩（會開新營地並確認）。
- 理想節奏：第 1 關約 100 隻熊、5–8 分鐘；第 2 關雪狼掉肉少但快，需先買武器；第 3 關巨熊在獵場深處，建議武器 Lv.3 後再打；第 4 關開始以助手與獵場擴張為主；第 5 關為無限賺錢的終局。
- 存檔版本 7：新增 `stage`、`unlocked`、`cleared`、`lifetime`；版本 6 存檔視為第 1 關並補滿 60 個獵物槽。

## 自動化階段、箭塔、三面熊群與戰績（2026-10-15 第六次發布）

使用者要求：武器升級要看得出差別；加回箭塔；熊是否四面都有；取名字與擊殺數（全球排行榜暫緩）；擴建後逐步自動化、最後全自動。

### 武器外觀
六個等級各一把原創模型：獵刀（短刃木柄）→ 鐵劍（直刃銅護手）→ 寬刃劍（寬厚雙叉護手）→ 大劍（長柄金柄頭）→ 霜刃（冰藍發光、刃側冰刺）→ 極光劍（青紫發光、光環）。揮砍扇形顏色隨等級變：粉紅 → 橘 → 冰藍 → 紫青。升級當場換武器並有閃光提示。

### 熊群分布與門
獵物分成三個密集群：北、西、南，各群由內向外分層（巨熊在群的外圈），東側留給客人雪道。營地南側新增第二個門；路徑規劃會選較近的門，門外路線會繞過營地四角，不再穿越柵欄（玩家點地、助手、獵人共用）。

### 名字與戰績
開場／暫停選單可輸入獵人名字（12 字內）。HUD 顯示名字與本關擊倒；選單顯示本關擊倒、生涯擊倒、生涯收入與各關最佳成績。資料隨存檔保存並跨關累計。全球排行榜未做：純前端無法防作弊且需後端，待使用者決定。
