# 冰原營地：已確認的開發方向

使用者於 2026-10-15 確認核心為「打熊 → 搬肉 → 加工 → 烹調 → 販售 → 擴建」，並授權以 Three.js 開發。此規格優先於原附件中的救援／夜襲生存規格。

## 第一版循環

1. 走近北極熊自動攻擊；允許移動中攻擊。
2. 擊倒熊掉落 8 份生肉；進入範圍自動拾取，容量初始 12。
3. 切肉台每 1.1 秒將一份生肉加工成一份肉排。
4. 烤爐每 1.8 秒將一份肉排變成一份餐點。
5. 櫃台每 0.65 秒售出一份餐點，初始單價 12 金幣。
6. 金幣可升級武器、容量及生產速度。
7. 擴建需 180 金幣，開啟北方獵場、第二烤爐；烹調效率翻倍，餐點單價變成 16。
8. 助手需 240 金幣，每秒把切肉台與烤爐的成品各搬一份到下游。玩家持續負責狩獵與生肉投料。

## 操作及儲存

PC 鍵盤／點地移動，手機與平板搖桿。工作站依物資類型從混合背包取料，不受堆疊順序阻擋。背包、加工佇列、加工進度、掉落物與敵人狀態皆保存。倒下回到營地並保留背包。

## 本版排除

沒有夜襲、村民飢餓、溫度、燃料消耗、鑽石、付費、廣告、遷徙與每日任務。圍欄是營地視覺邊界，不作塔防碰撞系統。

## 待實機驗收

iPhone Safari 直橫向、iPad Safari 直橫向、桌面 Chrome／Safari／Firefox；首次音效解鎖、螢幕旋轉、分頁切換、存檔恢復、觸控搖桿取消、完整首筆交易。需量測實際 FPS 才可設定支援效能下限。
